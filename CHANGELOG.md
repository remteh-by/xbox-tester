# Changes

## 1.2.0 debug preview

Graphite responsive UI with a genuine transparent controller photo and documented source. Fixed invalid ScrollView hierarchy and live-session rotation; circular stick backgrounds preserve their geometry. Clear unavailable/unmeasured trigger states, device requirement for rest tests, compact reports menu and 48dp actions. Optional RemTeh Ko-fi support in the footer/menu and after successful report saving/export; no payment-required features. Debug ads are disabled.

Raw measurements separated from display filters; explicit rest test; actual input-device ranges and motor capabilities; lifecycle cleanup; active device selection; validated JSON comparison, bounded local history and printable reports. Fixed original theme, layout class names and malformed XML. Signing secrets removed from source; Gradle/JDK compatibility pinned; release signing fails closed.

Physical acceptance and published release status are separate from these source changes. Existing published 1.0 packages remain unchanged.
